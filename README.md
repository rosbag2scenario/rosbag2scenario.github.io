# Rosbag2Scenario research supplement

Anonymous supplementary material for the submitted manuscript.

Published website: https://rosbag2scenario.github.io/

This repository contains the static website and its supporting evidence:

- `index.html`, `style.css`, `site.js`: the page and interactive views.
- `data/`: evaluation results, example trajectories and provenance records.
- `fig/`: figures and encounter motion plots.
- `media/`: encounter videos and preview images.

See `data/README.txt` for data definitions and provenance. The website uses
these prepared assets directly; no export scripts or build step are required.

GitHub Pages serves the root of the `main` branch.
